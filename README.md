# 🌌 3D N-Body Gravity Simulator

A 3D gravitational simulation of a solar system with eternal planetary trails.

## ✨ Features
- **N-body gravity** using 4th-order Runge-Kutta integration
- **3D camera** with rotation, zoom, and auto-rotation
- **Eternal trails** for planets (no length limits!)
- **Starry background** with twinkling stars
- **Time control** (speed up/slow down)
- **Realistic orbits** with perturbations

## 🎮 Controls
| Key | Action |
|-----|--------|
| `← → ↑ ↓` | Rotate camera |
| `+ / -` | Zoom in/out |
| `R` | Toggle auto-rotation |
| `O` | Toggle trails |
| `C` | Clear all trails |
| `Space` | Pause/Resume |
| `[ / ]` | Slow down / Speed up time |
| `ESC` | Exit |
